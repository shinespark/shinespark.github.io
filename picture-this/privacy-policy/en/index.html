Privacy Policy

Last updated: October 28, 2026

Picture This – Copy Any Image ("Picture This") is a Chrome extension that copies the image you right-click to the clipboard as PNG and keeps a short history of recent copies. This policy explains what data the extension handles.

Summary

  • Picture This does not send any data to the developer or to any third party.
  • It has no analytics, tracking, advertising, or remote code.
  • Everything it saves stays in your browser's local extension storage.

Data stored on your device

When you copy an image, the following is saved to chrome.storage.local:

  • The copied image (as PNG data)
  • The URL of the image
  • The URL of the page you were on (with the query string removed) and the page title
  • The image's width and height, and the time of the copy

The history size setting (10 / 20 / 30 / 50 items) is also stored.

When you choose "Save original image", the image file is saved to your downloads folder like any other download. It is not added to the history.

The history data is used only to show the history in the extension's popup so you can copy an image again or open its source page. Images larger than about 2 MB as data are copied but not saved.

Network requests

To copy or save an image, the extension downloads it from the server that hosts it, just as the page itself does when it displays the image. The request goes only to that image's server, and it may include that site's cookies, as the browser normally sends them. No other network requests are made.

Sharing

Picture This does not sell, transfer, or share your data with anyone. The developer cannot access it.

Deleting your data

  • Remove individual items with the × button on each thumbnail in the popup.
  • Clear everything with "Delete all" in the popup.
  • Uninstalling the extension deletes all stored data.

Changes
