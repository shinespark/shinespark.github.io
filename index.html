禁煙積立バンクNoSmokingBank

たばこ代を貯金と投資で見える化Quit smoking, grow savings

禁煙で浮いたたばこ代を毎日積み立て、もし投資に回していたらいくらになっていたかを同じグラフで確かめられます。値上げにも対応し、マイルストーンには通知でお知らせします。 Bank the cigarette money you no longer spend, every single day, and see what it would be worth if you had invested it instead, right on the same chart.

識別のアプリIdentify App

不思議のダンジョンのアイテム識別をサポートAn item identification log for Mystery Dungeon

「風来のシレン」や「トルネコの大冒険」の “もっと不思議のダンジョン” を攻略するためのアプリです。識別したアイテムをチェックして、未識別のアイテムをひと目で絞り込めます。杖・壺の価格チャートや、おまじないの記録にも対応しています。 A companion for the “Shiren the Wanderer” and “Torneko” Mystery Dungeon games. Check off the items you have identified and narrow down the unknown ones at a glance, with price charts for staffs and pots.

Herdr Agents for Stream Deck

AI コーディングエージェントの状態を Stream Deck に表示Your coding agents, on the Stream Deck keys

AI コーディングエージェント用のターミナルワークスペース「Herdr」とつながる Stream Deck プラグインです。各キーにエージェントが作業中・入力待ち・完了のどれかを表示し、押すとそのエージェントへ移動したり、コマンドを送ったりできます。 A Stream Deck plugin for Herdr, a terminal workspace for AI coding agents. Each key shows whether an agent is working, waiting for input or done, and a single press jumps to that agent or sends it a command.
