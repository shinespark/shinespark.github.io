Herdr Agents for Stream Deck

Show the state of your Herdr coding agents on the keys, and drive them without leaving the deck.

Herdr Agents is a plugin for the Elgato Stream Deck. It connects to Herdr, a terminal workspace for AI coding agents, and turns Stream Deck keys into a live view of those agents. Each key shows whether an agent is working, waiting for input or done, and a single press jumps to that agent or sends it a command.

It is downloadable desktop software that runs locally on the user's Mac.

Actions

Agent SlotShows one agent's state, repository and branch. Press to focus its pane.
Agent SummaryShows how many agents are in each state, and jumps to the agents that need attention. Can also be placed on the Stream Deck Neo Infobar.
New TabOpens a new Herdr tab.
Slash Command / Send TextSends a command or phrase to an agent.
Send KeysSends key presses such as esc to an agent.
CycleSteps through a list of values on each press, such as switching models.

Requirements

  • macOS
  • Stream Deck app
  • Herdr

Privacy

The plugin does not collect, store or send any personal data. It runs entirely on the user's computer and only communicates with the Herdr application on the same machine through a local socket. There is no account, no analytics and no network connection to external servers.
